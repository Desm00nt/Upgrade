# Кустик · Atria Dawn

**Кустик 1.0.1 · Minecraft Java 1.20.1 · Forge 47.4.0+ (ветка 47.x) · Java 17**

Сборка нацелена именно на Forge **47.4.0**. Минимальная версия в метаданных JAR берётся из той же настройки, что и зависимость сборки, чтобы эти требования не расходились.

У сухого кустика есть характер. И одна драгоценная палка. Поговори с ним — возможно, он захочет ею поделиться.

```text
/кустик Привет! Не скучно тебе одному среди песка?
/кустик Мне нужна веточка для факела, чтобы пережить ночь. Поделишься?
```

Это мод для **Forge**, не плагин Paper и не мод Fabric. Нейросеть работает через **API Atria Dawn**, а не запускается на компьютере игрока. Ответы не заготовлены и зависят от разговора. Нужны интернет и собственный API-ключ Atria.

## Как это работает

- Подойди к обычному **сухому кусту** (`minecraft:dead_bush`) на **4 блока** или ближе. Между вами не должно быть стены.
- Напиши **`/кустик <сообщение>`**. Латинский вариант — **`/kustik <сообщение>`**. Права оператора не нужны.
- Из видимых кустиков выбирается ближайший. Ответ приходит **лично тебе в чат** от имени «Кустик».
- Дождись ответа рядом с тем же кустом. Запрос идёт в фоне и не останавливает игровой поток.
- Кустик помнит последние **6 обменов репликами**. У каждого игрока с каждым кустом свой диалог.
- **Atria решает, убедил ли ты кустик.** Нет кодового слова, случайного броска или автоматической награды за число сообщений. По умолчанию палку можно получить не раньше второго успешного ответа.
- Если убедил — получишь **ровно одну палку**. Если инвентарь полон, она выпадет рядом с тобой.
- Один игрок может получить одну палку от кустика **в этом месте и измерении**. Полученные награды сохраняются с миром: перезаход, перезапуск, поломка и повторная посадка на том же месте не сбрасывают ограничение. Другие игроки могут уговорить его отдельно.

Обычное выпадение палок при разрушении сухого куста остаётся ванильным — мод его не меняет.

## Установка

### 1. Получи JAR

В репозитории — исходники и Gradle Wrapper. Установи **JDK 17**, открой терминал в папке проекта и выполни:

**Windows / PowerShell**

```powershell
.\gradlew.bat build
```

**Linux / macOS**

```bash
./gradlew build
```

Gradle установится автоматически; при первой сборке скачиваются зависимости Minecraft и Forge. Нужен доступ к их серверам и Maven Central.

После **успешной** сборки готовый мод:

```text
build/libs/kustik-1.20.1-1.0.1.jar
```

Не устанавливай `core/build/libs/*.jar`: это библиотека для разработки, не готовый мод.

**Вариант без локальной сборки:** после отправки изменений в GitHub workflow **Build Kustik** (`.github/workflows/build.yml`) собирает мод и прикладывает его к успешному запуску в **Actions → Artifacts → kustik-minecraft-1.20.1-forge**. Workflow запускается автоматически при push. Он также поддерживает `workflow_dispatch`; кнопка ручного запуска в GitHub доступна после добавления workflow в ветку по умолчанию. API-ключ для сборки не нужен.

Текущий статус проверок и ограничения среды: [docs/VERIFICATION.md](docs/VERIFICATION.md). Само наличие исходников или workflow не означает, что готовый JAR уже собран.

### 2. Установи мод

1. Установи [Forge для Minecraft 1.20.1](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html), **47.4.0 или новее в ветке 47.x**.
2. Положи `kustik-1.20.1-1.0.1.jar` в папку `mods` нужного игрового профиля или сервера. При обновлении убери старый JAR «Кустика» (например, версию 1.0.0), чтобы не было двух копий мода. Конфиг с ключом и данные мира удалять не нужно.
3. Запусти игру/сервер один раз. Появится `config/kustik-common.toml`.
4. Настрой ключ командой прямо в мире, как описано ниже. Если предпочитаешь редактировать файл — сначала закрой игру/сервер, затем запусти снова.
5. Найди сухой куст и заговори с ним.

**Одиночная игра:** мод и ключ находятся в папке твоего игрового профиля. В Minecraft Java папка часто называется `.minecraft`, но у отдельных сборок может быть своя.

**Мультиплеер:** достаточно установить мод и ключ **на Forge-сервер**. Игрокам не нужны ни ключ, ни клиентская копия этого мода. Установка только на клиент **не добавит команду** на чужом сервере. Другие моды сборки могут предъявлять свои требования к клиентам.

### 3. Подключи Atria Dawn

Создай ключ в [консоли Atria](https://api.atria-asi.ai/console/keys). Не отправляй его обычным сообщением, через команду разговора `/кустик`, в этот чат или в GitHub.

**Прямо в игре:** используй отдельную команду настройки (подставь свой ключ вместо `<API-ключ>`, без скобок и кавычек):

```text
/кустикключ <API-ключ>
```

Латинский вариант: `/kustikadmin key <API-ключ>`. Команда без ключа показывает справку.

- В одиночном мире доступна его **владельцу, даже без читов**. На сервере — оператору **уровня 4** или серверной консоли. Гости LAN и обычные игроки менять ключ не могут.
- Ключ сохраняется в `config/kustik-common.toml` и применяется **сразу, без перезапуска**. Предварительный запрос к Atria не выполняется: работоспособность ключа проверится при следующем разговоре.
- Старые ожидающие ответы отменяются, чтобы больше не использовать прежний ключ. История разговоров, ограничения запросов и полученные награды **не сбрасываются**.
- Удаление: `/kustikadmin clearkey`. Это очищает ключ в конфиге и отключает новые запросы, но **не отзывает** ключ у Atria и не стирает его из истории команд/резервных копий.
- Ответ команды не содержит ключ, не рассылается другим игрокам/операторам, а введённый ключ не добавляется в диалог с моделью или автодополнение.
- **Ввод не маскируется.** Команда может остаться в истории ввода Minecraft/консоли, сторонних логах и на скриншотах. Мод не может гарантировать их очистку. Для сервера безопаснее файл или переменная окружения.
- Если задан непустой `ATRIA_API_KEY`, команды установки/удаления **ничего не изменят** и объяснят причину. Сначала измени/удали переменную и перезапусти процесс — иначе она перекрыла бы сохранённый командой ключ.
- Если ключ не помещается в лимит команды самого Minecraft, используй файл или окружение. Мод принимает до 512 ASCII-символов токена; пробелы внутри, кавычки и управляющие символы отвергаются без показа введённого значения.

**Без ввода команды:** в уже созданном `config/kustik-common.toml` найди раздел `[atria]` и замени только значение `apiKey`:

```toml
[atria]
apiKey = "ВСТАВЬ_СВОЙ_API_КЛЮЧ_ЛОКАЛЬНО"
endpoint = "https://api.atria-asi.ai/v1/chat/completions"
model = "Atria-Dawn-Preview"
```

Остальные сгенерированные настройки можно оставить как есть. Файл хранит ключ открытым текстом: не публикуй его и защищай резервные копии.

**Для сервера предпочтительнее переменная окружения** `ATRIA_API_KEY`. Она имеет приоритет над `apiKey`. Например, задай её в панели хостинга либо в той же сессии терминала, из которой запускаешь Forge:

```bash
# Linux / macOS; значение указывай только на своём компьютере / сервере.
export ATRIA_API_KEY='ТВОЙ_КЛЮЧ'
./run.sh
```

```powershell
# Windows PowerShell
$env:ATRIA_API_KEY = "ТВОЙ_КЛЮЧ"
.\run.bat
```

`run.sh` / `run.bat` — стандартные скрипты установленного Forge-сервера, не файлы этого репозитория. Графический лаунчер не унаследует переменную из отдельного терминала: для одиночной игры обычно удобнее команда настройки или TOML. После изменения окружения перезапусти лаунчер/сервер; после ручного изменения TOML — переоткрой мир или перезапусти сервер. Команда настройки ключа перезапуска не требует.

Сервис Atria может иметь квоты и тарификацию. Мод не включает API-ключ или баланс. Используется [официальный Chat Completions API](https://api.atria-asi.ai/docs) с моделью `Atria-Dawn-Preview`.

## Команды

| Команда | Действие |
| --- | --- |
| `/кустик` или `/kustik` | Подсказка и уведомление об отправке сообщений в Atria |
| `/кустик <сообщение>` | Разговор с ближайшим видимым сухим кустом |
| `/kustik <сообщение>` | То же латиницей |
| `/кустикключ <API-ключ>` | Сохранить и сразу применить ключ; владелец одиночного мира, OP 4 или консоль |
| `/kustikadmin key <API-ключ>` | То же латиницей |
| `/kustikadmin clearkey` | Удалить ключ из конфига и отключить запросы; те же права |
| `/kustikadmin status` | Состояние подключения и число запросов; владелец одиночного мира, OP 2+ или консоль. Ключ не показывает |

Аргумент — весь текст до конца строки, без фигурных скобок и кавычек. Команды разговора доступны только игроку, не командному блоку/консоли.

## Настройки

Файл: **`config/kustik-common.toml`**. Настройки снимаются при запуске мира/сервера; после ручных изменений переоткрой мир/перезапусти сервер. Исключение — установка/удаление ключа административной командой: она обновляет и файл, и работающее подключение сразу.

| Раздел / поле | По умолчанию | Назначение |
| --- | --- | --- |
| `atria.apiKey` | пусто | Ключ из файла или команды, если не задан `ATRIA_API_KEY` |
| `atria.endpoint` | `https://api.atria-asi.ai/v1/chat/completions` | Полный адрес Chat Completions, а не только `/v1` |
| `atria.model` | `Atria-Dawn-Preview` | Регистр букв важен |
| `atria.reasoningEffort` | `none` | Короткий разговор без долгого reasoning; `""` не отправляет это поле |
| `atria.maxTokens` | `2048` | Лимит ответа API; не длина видимой реплики |
| `atria.timeoutSeconds` | `90` | Общий дедлайн, включая чтение тела ответа |
| `gameplay.radius` | `4` | Радиус поиска, от 1 до 8 блоков |
| `gameplay.minimumTurns` | `2` | Минимум успешных ответов до возможной награды; `1` разрешает награду с первого ответа |
| `gameplay.historyTurns` | `6` | Сколько полных пар реплик хранить в контексте |
| `gameplay.memoryMinutes` | `15` | Время простоя до забывания диалога |
| `gameplay.maxSessions` | `512` | Общий предел диалогов в памяти; самые давние вытесняются |
| `gameplay.maxMessageLength` | `240` | Предел сообщения в Unicode-символах; у самого Minecraft тоже есть лимит команды |
| `limits.playerCooldownSeconds` | `4` | Пауза между запросами игрока |
| `limits.maxConcurrentRequests` | `4` | Максимум запросов в работе на весь сервер |
| `limits.requestsPerMinute` | `30` | Скользящий минутный лимит всех игроков вместе |

История не записывается на диск и забывается при выходе игрока или остановке сервера. История и право на награду — разные вещи: забывание разговора **не восстанавливает палку**.

Права на уже выданные награды хранятся в `<папка мира>/data/kustik_rewards.dat`. Не удаляй этот файл ради очистки истории: это сбросит ограничения наград. Вместе с ним сохраняются UUID игрока, измерение и координаты полученной награды, но не текст разговора.

## Безопасность и приватность

- В Atria отправляются **только** реплики этой команды, ограниченная история диалога, правила персонажа и флаги игрового состояния. Обычный чат не перехватывается. Мод не добавляет к запросу ник, UUID, координаты, IP, файлы мира или инвентарь.
- Уведоми игроков, что их реплики обрабатывает внешний сервис. Не вводи личные данные или секреты. Сам чат Minecraft и сторонние моды могут иметь собственное логирование.
- Команды `/кустикключ` и `/kustikadmin key` — отдельные административные пути, не подкоманды разговора: ключ не попадёт в AI-историю при отказе в доступе. Для владельца одиночного мира проверяется исходный отправитель, а не персонаж, подставленный через `/execute as`. Командные блоки/функции с уровнем 2 не могут менять ключ.
- Ключ используется только логическим сервером. Намеренно выбран Forge-конфиг **COMMON**, а не автоматически синхронизируемый `SERVER`-конфиг. Мод не рассылает ключ клиентам и не пишет запросы, ответы или секреты в свой серверный лог.
- Только HTTPS; HTTP разрешён лишь для локального тестового сервера (`localhost`, `127.0.0.1`, `::1`). Перенаправления HTTP запрещены. Меняй endpoint только на доверенный: он получит ключ и диалог.
- Максимум один запрос на игрока одновременно; число рабочих потоков, частота, длина истории и ответа ограничены. Автоматических повторов платного запроса нет.
- Ответ должен быть JSON с **ровно** двумя полями: `reply` (строка) и `give_stick` (boolean). Ошибочный, оборванный или слишком большой ответ не выдаёт предметы. Reasoning не показывается игроку.
- Нейросеть **не выполняет команды**. Текст выводится как обычный текст; сервер может выдать только `Items.STICK`, строго одну штуку, после повторной проверки игрока, расстояния, куста и сохранённого ограничения.
- При выходе игрока, поломке куста игроком и остановке сервера ожидающие запросы отменяются. Если к моменту ответа куст исчез, игрок умер, ушёл слишком далеко или находится в другом измерении, результат не засчитывается.
- Инструкции персонажа помогают против подмены роли, но не являются абсолютной защитой от prompt injection. Жёсткие ограничения наград работают независимо от решения модели.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Неизвестная команда | Запущены именно Minecraft **Java 1.20.1**, Forge **47.x ≥ 47.4.0**, JAR находится в `mods` на стороне сервера/одиночной игры |
| «Рядом нет сухого кустика» | Нужен именно `dead_bush`, не трава или другой куст. Подойди ближе и убери стену |
| «Кустик пока без голоса» | Владелец мира/OP 4 может задать ключ командой `/кустикключ <API-ключ>`. Для ручной настройки файла нужен перезапуск мира/сервера |
| Команда ключа недоступна | Проверь права: в одиночной игре — владелец мира, на сервере — OP 4. В консоли команда вводится без `/` |
| Команда сообщает о `ATRIA_API_KEY` | Переменная имеет приоритет. Измени/удали её и перезапусти процесс, прежде чем настраивать ключ командой |
| «Atria не приняла API-ключ» | Ключ действителен? Нет ли старого значения в `ATRIA_API_KEY`, которое перекрывает TOML? |
| Лимит / сервис недоступен | Проверь квоту и состояние Atria; подожди. Это не выдаёт наград и не засчитывает реплику |
| Таймаут | Проверь исходящий HTTPS с машины сервера. Можно увеличить `timeoutSeconds` до 180 |
| Ответ «невнятный» | Atria вернула не ожидаемый JSON/оборвала генерацию. Повтори запрос; при включённом reasoning верни `none` либо увеличь `maxTokens` |
| Сборка не скачивает Gradle/Forge | Нужен JDK 17 и сетевой доступ к серверам зависимостей. См. [проверки](docs/VERIFICATION.md) |

## Разработка и тесты

```bash
./gradlew -p core test   # HTTP-клиент, ключи, JSON, память, лимиты и награды; без Minecraft и API-ключа
./gradlew build          # Полная сборка, core-тесты, NBT/Forge-конфиг-тесты и reobfJar
./gradlew runClient      # Тестовая игра в папке run/
./gradlew runServer      # Тестовый выделенный сервер (нужно самостоятельно принять EULA)
```

- `core/` — независимая Java-библиотека с HTTP-клиентом и тестами на локальном mock HTTP-сервере.
- `src/main/java/` — адаптер Forge: команды, поиск куста, поток сервера, инвентарь и `SavedData`.
- `core/src/main/resources/kustik/bush-system.txt` — характер кустика и правила ответа.
- [Ручные проверки в игре](docs/TESTING.md) — одиночный мир, мультиплеер, награды и ошибки.

Нужен доступ к Maven Central для обычного Gradle-запуска core-тестов. Мок не притворяется настоящей Atria: он проверяет протокол, а не качество убеждения. Реальная модель и механика внутри Minecraft требуют отдельного игрового прогона с настроенным API.

**Лицензия:** MIT. Gradle Wrapper распространяется на условиях Apache-2.0, указанных в его скриптах. Minecraft, Forge и Atria — отдельные проекты; мод не является их официальным продуктом.
